# .dotfiles 按键说明

## 通用按键

| 按键          | 功能                          | 模式   |
|---------------|-------------------------------|--------|
| `<leader>`    | 领导键（默认 `, `）           | n/x    |
| `H` / `L`     | 行首 / 行尾                   | x/n/o  |
| `^` / `$`     | 行首 / 行尾                   | n      |
| `v`           | 进入可视模式                  | n      |
| `V`           | 进入行可视模式                | n      |
| `u` / `U`     | 撤销（带反馈）                | n      |
| `Ctrl-r`      | 恢复上次撤销                  | n      |

## 移动与窗口

| 按键               | 功能                     | 模式   |
|--------------------|--------------------------|--------|
| `Ctrl + j/k/h/l`   | 上下左右切换窗口        | n      |
| `Ctrl + b`         | 上一个窗口              | n      |
| `<C-w>o`           | 关闭其他窗口            | n      |
| `Ctrl + w +` / `-` | 窗口大小调整            | n      |
| `<C-w><` / `>`     | 窗口宽度调整            | n      |
| `Ctrl + w + p`     | 上一个窗口              | n      |

## 文本操作

| 按键                  | 功能                     | 模式   |
|-----------------------|--------------------------|--------|
| `Ctrl + c`            | 复制选区                | x      |
| `Ctrl + v`            | 粘贴                    | n      |
| `<leader>xx`          | 外部命令执行            | n      |
| `Ctrl + a` / `Ctrl + x` | 布尔值切换              | n      |
| `m`                   | 选择最后插入的文本      | n      |

## 其他重要按键

| 按键               | 功能                     | 模式   |
|--------------------|--------------------------|--------|
| `<leader>fs`       | 切换到 `~/.dotfiles`     | n      |
| `<leader>ft`       | 切换到 `~/test`          | n      |
| `<leader>vn`       | 切换行号显示             | n      |
| `<leader>vp`       | 切换粘贴模式             | n      |
| `<leader>vm`       | 切换鼠标模式             | n      |
| `<leader>vl`       | 切换光标线              | n      |
| `<leader>vf`       | 切换折叠列              | n      |
| `<leader>vd`       | 窗口差异视图             | n      |
| `<leader>xu` / `xU` | Unicode 转义/反转义      | x      |
| `<leader>xz` / `xZ` | 繁简转换                | x/n    |

## 特殊模式

- **Visual 模式**：`<leader>/` 进入选区搜索
- **Command 模式**：支持上下箭头历史导航

---

**说明**：
- 所有按键都通过 `mappings.lua` 统一管理。
- 部分按键会调用自定义模块（`ext/` 中的功能）。
- 更多细节请查看 `vim/lua/lu5je0/mappings.lua` 或 `:Lazy` 查看插件按键。
